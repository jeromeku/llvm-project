## Quick Start

### Building with RTTI Examples

```bash
# Compile with RTTI enabled (default)
g++ -o rtti-example-with-rtti rtti-example.cpp -std=c++17

# Compile without RTTI
g++ -o rtti-example-no-rtti rtti-example-no-rtti.cpp -std=c++17 -fno-rtti

# Run the examples
./rtti-example-with-rtti
./rtti-example-no-rtti

# Compare binary sizes
ls -lh rtti-example-*
size rtti-example-*
```

### Building the nanobind Extension

```bash
# Configure with CMake
cmake -S . -B build -G Ninja

# Build
ninja -C build

# The extension will be: build/my_ext.cpython-*.so
```

## Symbol Analysis

### With RTTI - Contains:
- `typeinfo` structures for each polymorphic class
- `typeinfo name` symbols (mangled names like "3Dog")
- Enhanced vtables with typeinfo pointers

### Without RTTI - Only Contains:
- Basic vtables (8 bytes smaller per vtable)
- No typeinfo symbols
- No RTTI-related code

## Debugging Commands

```bash
# View RTTI symbols
nm -C binary | grep -i typeinfo

# Compare segment sizes
size binary-with-rtti binary-without-rtti

# Check type name strings
strings binary | grep -E "^[0-9]+(Dog|Cat|Bird)"

# View read-only data section
objdump -s -j .rodata binary

# List all symbols
nm -C binary | less

# View Ninja dependency graph
ninja -C build -t graph | dot -Tpng > graph.png

# Show compilation database
cat build/compile_commands.json | jq
```
